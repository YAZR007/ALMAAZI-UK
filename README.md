## 🚀 How to Run Locally

Simply double-click `index.html` or open it in any web browser:
```powershell
Start-Process index.html
```

---

## 🌐 Deploy to GitHub Pages

1. Push this repository to GitHub:
   ```bash
   git remote add origin https://github.com/<your-username>/almaazi.git
   git branch -M main
   git push -u origin main
   ```
2. In your GitHub repository settings, navigate to **Pages** > **Source** > Select `main` branch > Click **Save**.
3. Your luxury site will be live instantly with zero build steps!
